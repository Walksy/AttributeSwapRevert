<h1>Atttribute Swap Revert</h1>

Reverts the patch made on Minecraft 26.2-Pre-2 that removes attribute swapping. Mojang achieved this by deferring hotbar inputs so they're processed after your attack/use inputs. Along with removing attribute swapping, this also makes PvP in general feel sluggish as you can no longer perform combos like swapping to a block and placing it within the same tick.
